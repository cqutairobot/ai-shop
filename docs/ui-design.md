# UI 设计说明书 · 极光 Aurora

> 配套预览页：[`ui-preview.html`](ui-preview.html)。用浏览器打开就能点，里面是示例数据。本文的数值都以预览页的实现为准。
> 对应的功能范围见：[首版（V1）功能说明](v1-features.md)。

## 1. 设计方向

**一句话**：深色背景上有缓慢流动的极光，商品像一张张发光的玻璃卡片摆在上面。

整套视觉由五个元素组成：

1. **极光背景**：三团彩色光晕在页面后方缓慢漂移，永远在动，但不抢内容。
2. **玻璃卡片**：半透明的卡片，带一圈细描边，鼠标移上去会有光斑跟着走。
3. **渐变强调**：店名、价格用渐变色文字，主按钮是发光的渐变胶囊。
4. **大圆角**：卡片 20px，弹层 28px，按钮和标签是全圆角胶囊。
5. **自动封面**：商品没上传图片时，系统按商品生成一张渐变封面，页面不会出现灰色占位图。

三条设计原则，取舍时按这个顺序：

1. **内容第一**。商品名、价格、联系按钮永远最显眼，装饰和动画不能挡住它们。
2. **动得多，但不拖慢操作**。任何动画播放期间页面都可以点击，没有需要等它播完的动画。
3. **手机优先**。访客大多从微信、QQ 里点开，先保证手机上好看、流畅，再增强电脑端效果。

深色是招牌外观，同时提供完整的浅色版本。默认跟随访客的系统设置，访客手动切换后记住选择。

## 2. 颜色

所有颜色都是 CSS 变量，组件里不直接写色值。

### 2.1 基础色

| 变量 | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--bg` | `#07080D` | `#F5F6FB` | 页面底色 |
| `--bg-elev` | `#0E1018` | `#FFFFFF` | 头像底等实心小面积 |
| `--surface` | 白 4.5% | 白 74% | 卡片、输入框、标签条的半透明填充 |
| `--surface-hover` | 白 9% | 黑 6% | 悬停、数量角标、次级填充 |
| `--surface-solid` | `#131520` | `#FFFFFF` | 弹层、提示条等必须不透明的面 |
| `--border` | 白 9% | 黑 8% | 默认描边 |
| `--border-strong` | 白 18% | 黑 16% | 弹层、次级按钮描边 |
| `--text` | `#F2F4FA` | `#0E1020` | 正文、标题 |

### 2.2 主题色

一套主题色由三个极光色和一对按钮渐变色组成。后台提供 5 套预设，默认是极光紫。

| 预设 | `--accent` | `--accent-2` | `--accent-3` | 按钮渐变 `--cta-from` → `--cta-to` | 按钮上白字对比度 |
|---|---|---|---|---|---|
| 极光紫（默认） | `#7B61FF` | `#3EC8FF` | `#FF6BCB` | `#6C4DFF` → `#3D63F2` | 5.07 / 4.92 |
| 深海蓝 | `#3B82F6` | `#22D3EE` | `#8B5CF6` | `#2563EB` → `#4F46E5` | 5.17 / 6.29 |
| 薄荷青 | `#14B8A6` | `#4ADE80` | `#38BDF8` | `#0F766E` → `#0E7490` | 5.47 / 5.36 |
| 落日橙 | `#FF7A45` | `#FFC53D` | `#FF4D8D` | `#C2410C` → `#BE185D` | 5.18 / 6.04 |
| 樱花粉 | `#F472B6` | `#C084FC` | `#FB7185` | `#C81E6E` → `#9333EA` | 5.43 / 5.38 |

三个极光色用在背景光晕、头像光环、卡片光斑和渐变文字上。按钮渐变色用在所有「白字 + 彩色底」的地方：主按钮、选中的分类、步骤序号。

如果店主在后台自选主色，系统按下面的规则补全其余颜色：

- `--accent-2` 取主色色相减约 60° 并提亮，`--accent-3` 取主色色相加约 60°（按 OKLCH 色彩空间计算）。
- 按钮渐变色由主色加深得到，加深到白字对比度不低于 4.5 为止。

### 2.3 派生色

下面的颜色由主题色算出来。后台保存主题色时由服务端算好写进 CSS 变量，前端不依赖浏览器的实时混色能力。

| 变量 | 深色算法 | 浅色算法 | 默认主题下的色值（深 / 浅） | 用途 |
|---|---|---|---|---|
| `--accent-text` | 主色混 38% 白 | `--cta-from` 混 12% 黑 | `#AD9DFF` / `#5F44E0` | 彩色小字、图标、列表圆点 |
| `--grad-text` | 三色各混 30–40% 白 | 三色各混 20–45% 黑 | `#B0A0FF → #78D9FF → #FF97DB` / `#624ECC → #226E8C → #9E427E` | 价格等小号渐变字，对比度不低于 4.5 |
| `--grad-display` | 同 `--grad-text` | 三色各混 8–34% 黑 | 同上 / `#7159EB → #2984A8 → #CC56A2` | 店名大标题，对比度不低于 3 |

联系方式的品牌色固定：微信 `#07C160`，QQ `#12B7F5`。

### 2.5 对比度要求

- 正文和小字对背景的对比度不低于 4.5，24px 以上的粗体大字不低于 3。
- 上面表格里的文字色都已按此核对过。新增颜色时同样要核对。

## 3. 字体与字号

| 变量 | 字体 | 用途 |
|---|---|---|
| `--font-body` | 系统字体：苹方、鸿蒙黑体、MiSans、微软雅黑 | 所有中文和正文 |
| `--font-display` | Outfit（可变字重，开源协议 OFL），中文回落到系统字体 | 价格、数字、店名里的英文 |

## 4. 间距、圆角与断点

**间距**以 4px 为单位：4、8、12、16、20、24、32、40、56。常用值：卡片内边距 12px（电脑 16px），卡片间距 12 / 16 / 20px，区块间距 20–24px。

| 圆角变量 | 值 | 用途 |
|---|---|---|
| `--r-xs` | 6px | 标签 |
| `--r-sm` | 12px | 小封面、菜单项 |
| `--r-md` | 16px | 联系方式条、步骤卡、菜单 |
| `--r-lg` | 20px | 商品卡片、正文面板 |
| `--r-xl` | 28px | 弹层、底部面板 |
| `--r-full` | 999px | 按钮、分类、搜索框、公告条 |

详情页大封面用 24px，介于卡片和弹层之间。

| 断点 | 页面边距 | 商品列数 | 其他变化 |
|---|---|---|---|
| 小于 640px | 16px | 2 | 搜索框收成圆形图标；联系面板从底部滑出 |
| 640px 起 | 24px | 3 | 卡片内边距加大 |
| 768px 起 | 24px | 3 | 搜索框常驻展开；联系面板变成居中弹窗；底栏按钮固定宽度 |
| 900px 起 | 24px | 3 | 详情页变成左图右文两栏 |
| 1024px 起 | 32px | 4 | 内容最大宽度 1200px，详情页 1040px |

**层级**（`z-index`）：背景 -1，分类条 20，回到顶部 25，顶栏 30，底部购买栏 40，弹层 60，轻提示 80。

## 5. 质感

**背景**由三层叠成，固定在页面后方：

1. 三团光晕。每团直径 72vmax，用「径向渐变到透明」画出来，透明度深色 50%、浅色 34%（第三团再减半）。
2. 点阵网格。26px 间距的小圆点，只在页面顶部可见，向下渐隐。
3. 噪点。8% 透明度的细颗粒叠加，让渐变不发灰、不出现色带。

**玻璃面**有两种做法，按面积选用：

- 大面积且数量多的元素（商品卡片、标签条）只用半透明填充，不做背景模糊。
- 贴边悬浮的条（顶栏、分类条、底部购买栏）用背景模糊 18px 加饱和度 160%。

**描边**统一 1px。卡片悬停时描边变成跟随鼠标位置的渐变光边。

**阴影**：卡片在深色下用「顶部 1px 内高光 + 深色投影」，浅色下用两层柔和投影。悬停时加一层主题色的彩色投影。主按钮自带同色发光。

**自动封面**：比例 4:3。底色由三个径向渐变叠成，色相取自商品（每个商品一个固定色相，相邻商品错开）。上面叠一层细网格，中间放一块玻璃质感的圆角方块，里面是分类图标。店主上传了图片就显示图片，没上传或图片加载失败就显示自动封面。缺货商品的封面做灰度和压暗处理。

**图标**：线性图标，线宽 1.7px，圆头圆角，常用尺寸 20px。全部内联成 SVG，不用图标字体。

## 6. 动效系统

### 6.1 三个层次

| 层次 | 作用 | 节奏 |
|---|---|---|
| 环境层 | 让页面「活着」：背景、光环、流光 | 慢，循环播放，周期 2 秒以上 |
| 编排层 | 内容怎么出现、怎么换场 | 一次性，300–800ms，多个元素依次错开 |
| 反馈层 | 回应每一次悬停、点击、复制 | 快，120–320ms |

### 6.2 时长与曲线

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--dur-1` | 120ms | 按压 |
| `--dur-2` | 200ms | 悬停、颜色变化、淡入淡出 |
| `--dur-3` | 320ms | 小元素位移、展开、退场 |
| `--dur-4` | 480ms | 弹层、面板、回弹 |
| `--dur-5` | 800ms | 封面缩放、首屏主角 |
| `--ease-out` | `cubic-bezier(.16, 1, .3, 1)` | 进场，先快后慢 |
| `--ease-in` | `cubic-bezier(.5, 0, .75, 0)` | 退场，先慢后快 |
| `--ease-in-out` | `cubic-bezier(.65, 0, .35, 1)` | 来回位移、循环动画 |
| `--ease-spring` | `cubic-bezier(.34, 1.56, .64, 1)` | 带一点回弹的出现 |

通用规则：退场比进场快；依次出现的元素每个错开 40–80ms，最多错开 8 个。

### 6.3 环境层

| 编号 | 名称 | 表现 | 参数 |
|---|---|---|---|
| A1 | 极光漂移 | 三团光晕各自缓慢移动并缩放，往返循环 | 周期 26 / 32 / 38 秒，`--ease-in-out` |
| A2 | 背景视差 | 光晕随鼠标反向轻微偏移。仅电脑 | 最多 ±14px，900ms |
| A3 | 头像光环 | 头像外圈的三色渐变环匀速旋转，外面带一圈模糊光晕 | 8 秒一圈，匀速 |
| A4 | 在线呼吸 | 头像右下的绿点向外扩散一圈波纹 | 2 秒一次 |
| A5 | 店名流光 | 店名的渐变色左右缓慢流动 | 7 秒，往返 |
| A6 | 公告跑马灯 | 公告文字向左循环滚动，首尾相接。悬停时暂停 | 约 40px/秒，进页面 1.6 秒后开始 |
| A7 | 按钮扫光 | 主按钮上周期性扫过一道高光 | 4.2 秒一次，扫光过程约 1.2 秒 |
| A8 | 骨架屏流光 | 加载占位块上的高光从右向左流动 | 1.4 秒，匀速 |
| A9 | 空状态浮动 | 「没找到」插画上下轻轻浮动 | 4 秒，往返，幅度 10px |
| A10 | 二维码扫描线 | 一条发光细线在二维码上来回扫 | 2.4 秒，往返 |

### 6.4 编排层

| 编号 | 名称 | 触发 | 表现 | 参数 |
|---|---|---|---|---|
| E1 | 首屏编排 | 打开首页 | 头像弹出，然后店名、简介、数据、按钮、公告、分类条依次上浮出现。数据里的数字从 0 滚到目标值 | 头像 800ms 回弹；其余 620ms，每项错开 80ms；数字滚动 900ms |
| E2 | 卡片入场 | 卡片滚进屏幕 12% | 从下方 28px、缩小到 97% 的位置上浮到位。每张只播一次 | 520ms，同批错开 55ms |
| E3 | 分类指示器 | 切换分类 | 选中底色从旧分类滑到新分类，宽度随文字变化 | 位移 480ms 回弹，宽度 320ms |
| E4 | 筛选重排 | 切换分类或搜索 | 不符合的卡片先缩小淡出；留下的卡片滑到新位置；新出现的卡片放大淡入 | 淡出 150ms；滑动 440ms；淡入 380ms，错开 40ms |
| E5 | 搜索框展开 | 点搜索图标 | 手机上圆形图标展开成整行输入框，分类同时淡出。聚焦时描边点亮并带一圈光晕，放大镜微微转动 | 展开 320ms；光晕 200ms |
| E6 | 顶栏收缩 | 下滑超过 96px | 顶栏变成毛玻璃，小头像和店名上浮出现，「联系我」按钮弹出 | 320ms；按钮回弹 |
| E7 | 分类条吸顶 | 分类条滚到顶栏下方 | 分类条固定并出现毛玻璃底 | 200ms |
| E8 | 页面转场 | 点商品卡片或返回 | 卡片封面直接变形放大成详情页大封面，其余内容交叉淡入。返回时反向播放，并回到原来的滚动位置 | 封面变形 460ms；淡入 280ms |
| E9 | 详情入场 | 进入详情页 | 商品名、标签、价格、步骤、正文依次上浮出现 | 560ms，每项错开 70ms |
| E10 | 购买栏滑入 | 进入详情页 | 底部购买栏从屏幕下方滑入 | 480ms |
| E11 | 回到顶部 | 下滑超过 520px | 圆形按钮回弹出现，外圈圆环显示当前滚动进度 | 320ms 回弹 |

### 6.5 反馈层

| 编号 | 名称 | 触发 | 表现 | 参数 |
|---|---|---|---|---|
| F1 | 卡片悬停 | 鼠标移到卡片上 | 卡片上浮 6px 并随鼠标位置倾斜；光斑和渐变光边跟着鼠标走；封面放大到 107%；图标方块上跳；右下角出现箭头；投影带上主题色 | 倾斜最多 ±4°；200ms；封面 800ms |
| F2 | 卡片按压 | 手指按下卡片 | 缩小到 97%，松开回弹 | 120–200ms |
| F3 | 按钮 | 悬停或按下 | 悬停时变亮、发光增强；按下缩小到 96%。电脑上主按钮有磁吸效果，会被鼠标轻轻带着走 | 按压 120ms；磁吸位移为鼠标偏移的 18%（横）和 30%（纵） |
| F4 | 涟漪 | 点击按钮或分类 | 从点击位置扩散出一圈水波 | 620ms |
| F5 | 复制成功 | 点「复制」 | 按钮文字上滑消失，原位画出一个对勾，按钮变绿；顶部弹出轻提示；手机轻震一下。2 秒后恢复 | 对勾 320ms；震动 10ms |
| F6 | 轻提示 | 复制、分享等 | 从屏幕顶部回弹落下，停留后向上收回 | 进 480ms 回弹；停留 2 秒；出 320ms |

| F8 | 二维码展开 | 点「二维码」 | 面板向下撑开，二维码从倾斜缩小的状态翻正放大 | 480ms 回弹 |
| F9 | 公告弹窗 | 首次进入或点公告条 | 弹窗从 90% 回弹放大出现，关闭时快速缩小淡出 | 进 480ms；出 200ms |
| F10 | 深浅色切换 | 点太阳 / 月亮按钮 | 新主题以按钮为圆心向全屏扩散；图标旋转变形 | 560ms |
| F11 | 主题色切换 | 选择主题色 | 全页颜色交叉淡入 | 280ms |
| F12 | 图片渐显 | 商品图片加载完成 | 从模糊的小图过渡到清晰大图 | 320ms |
| F13 | 图片放大 | 点详情正文里的图片 | 图片从原位置放大到全屏，可双指缩放，下拉关闭 | 320–480ms |

### 6.6 降级

- **系统开启「减少动态效果」时**：环境层全部停止；编排层和反馈层改成 150ms 以内的淡入淡出；倾斜、视差、磁吸关闭。功能和布局不变。
- **不支持页面转场的浏览器**：E8 退化为直接切换加 E9 的内容上浮；F10 退化为直接换色。
- **轻量模式**：设备内存不超过 4GB 或访客开了省流量时，停掉 A1 和 A2，关闭背景模糊，其余动效保留。

## 8. 页面

### 8.1 首页

从上到下：

1. **顶栏**（高 56px，吸顶）。刚进页面时透明，只有右侧的主题色和深浅色两个按钮。下滑后变成毛玻璃，左侧出现小头像和店名，右侧多出「联系我」按钮。
2. **头部**（居中）。头像 84px（电脑 100px）、店名、一句话简介、三项数据、「联系我」和「店铺公告」两个按钮。
3. **公告条**。
4. **分类条**（吸顶，贴在顶栏下方）。左侧是可横向滑动的分类，右侧是搜索。
5. **商品网格**。
6. **页脚**。居中小字，上方一条细分隔线。

### 8.2 商品详情页

- **顶栏**始终是毛玻璃，左侧是返回按钮、小头像和店名。
- **手机**上单列：大封面、商品名、标签、价格（含划线原价和「立省」角标）、三步购买流程、图文详情面板。
- **电脑**上两栏：左侧大封面在滚动时固定，右侧是全部文字内容。
- **底部购买栏**固定在屏幕底部，毛玻璃底。左侧是分享按钮和价格，右侧是「联系购买」。手机上按钮占满剩余宽度，电脑上固定 280px 靠右。
- **缺货商品**：封面变灰，角标显示「缺货」，底栏按钮变成灰色的「暂时缺货，咨询到货时间」，仍然可以点开联系面板。

图文详情里的排版规则：

- 小标题 17px 加粗；正文和列表用 `--text-2`；加粗文字用 `--text`；列表圆点用 `--accent-text`。
- 需要强调的内容用「提示框」，不用大段红字。提示框只有蓝色提示和橙色注意两种。
- 图片圆角 12px，宽度占满面板，点击可放大。

### 8.3 联系面板

从上到下：标题和关闭按钮、当前商品摘要（小封面、名称、价格）、咨询语框、微信条、可展开的二维码、QQ 条、在线时间说明。

- 从首页的「联系我」打开时没有商品摘要，咨询语换成通用的问候语。
- 手机上是底部面板，最高占屏幕 92%，内容超出时在面板内滚动。电脑上是 440px 宽的居中弹窗。
- 点遮罩、点关闭按钮、按 Esc、手机上下拉，都可以关闭。

### 8.4 公告弹窗

居中弹窗，最宽 420px。内容是「店铺公告」小标签、标题、正文，底部两个按钮：「不再提醒」和「我知道了」。正文超过屏幕高度 60% 时在弹窗内滚动。

### 8.5 管理后台

后台沿用同一套颜色、字体、圆角和组件，但使用「安静模式」：没有极光背景和卡片倾斜，只保留按钮、弹层、提示这些反馈层动效。后台以表单和列表为主，优先保证操作效率。

## 9. 内容与边界情况

| 情况 | 处理方式 |
|---|---|
| 店名过长 | 建议 16 字以内。超出时自动换行，最多两行 |
| 简介过长 | 建议 40 字以内。两行文字自动均衡换行 |
| 商品名过长 | 建议 40 字以内。卡片上最多两行，超出显示省略号；详情页完整显示 |
| 标签过多 | 卡片上只显示一行，放不下的隐藏；详情页全部显示。单个标签建议 6 字以内 |
| 价格位数多 | 卡片价格超过 5 位字符时字号降到 18px |
| 价格是文字 | 「面议」这类文字用正文字体显示，建议 4 字以内 |
| 分类很多 | 手机和电脑都保持单行横向滑动，右侧渐隐提示还有更多 |
| 没有上传封面 | 显示自动封面 |
| 图片加载失败 | 回退到自动封面 |
| 正在加载 | 显示 8 张骨架卡片。超过 8 秒还没加载完，显示「加载有点慢，点此重试」 |
| 加载失败 | 显示出错插画、一句说明和「重试」按钮 |
| 搜索或筛选没有结果 | 显示空状态：插画、「没有找到相关商品」、一句建议和「清除筛选」按钮 |
| 店里还没有商品 | 显示空状态：「店主还在上架商品」和「联系我」按钮 |
| 打开已下架商品的链接 | 显示「商品已下架」和「回到首页」按钮 |
| 浏览器不允许复制 | 弹出一个可以长按选中的文本框，让访客手动复制 |
| 微信里无法直接唤起 QQ | 提示「请复制 QQ 号后到 QQ 里添加」 |
| 网络很慢 | 文字和布局先出现，图片后到；所有图片预留好宽高，加载过程中页面不跳动 |

## 10. 无障碍

- **对比度**按 2.5 节执行。
- **不只靠颜色**传达信息：缺货有文字角标，复制成功有对勾和提示文字。
- **键盘**：所有可点击的元素都能用 Tab 键到达，顺序与视觉顺序一致。聚焦时显示 2px `--accent-2` 外框，偏移 3px。
- **弹层**：打开后焦点移到弹层内并限制在弹层内循环；按 Esc 关闭；关闭后焦点回到触发它的按钮。
- **读屏**：
  - 图标按钮都有文字说明，例如「回到顶部」「切换深色 / 浅色」。
  - 分类按钮标明是否选中。
  - 弹层标明为对话框。
  - 轻提示和商品列表的变化会被朗读。
  - 纯装饰的背景、重复的跑马灯文字对读屏隐藏。
- **动效**按 6.6 节降级。

## 11. 性能与实现约定

服务器在海外，访客主要在国内，所以资源体积和请求数要控制得比较严。

- **全部资源自托管**。不引用任何境外公共 CDN 或在线字体服务，它们在国内访问不稳定。
- **动画只改变位移、缩放、旋转和透明度**，不触发重新排版。光晕用径向渐变绘制，不对大面积元素使用模糊滤镜。
- **背景模糊同屏不超过 3 处**（顶栏、分类条、底部购买栏），弹层打开时另加遮罩一处。
- **不引入大型动画库**。入场动画用浏览器自带的滚动观察和动画接口，页面转场用 View Transitions，其余用 CSS。前台脚本压缩后不超过 60KB。
- **图片**用 WebP 格式，列表缩略图宽度不超过 480px，懒加载，带模糊小图占位。
- **性能目标**（中端安卓手机，4G 网络）：首屏主要内容 2.5 秒内出现；页面布局偏移不超过 0.05；滚动和动画保持 60 帧。
- **主题**：在 `<html>` 上用 `data-theme="dark"` 或 `"light"` 切换，默认跟随系统，访客手动切换后保存在本地。
- **主题色**：后台保存时由服务端算出 2.2 和 2.3 节的全部变量，输出到页面。
