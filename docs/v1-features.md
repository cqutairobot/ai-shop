# AI 商品展示网站 · 首版（V1）功能说明

> 参考页面：<https://www.16688.com.cn/shop/S744042>
> 状态：首版已按本文实现。部署和使用方法见 [README](../README.md)。

## 1. 定位

一个只属于你自己的店铺主页：访客打开就能看到全部商品，点进去看介绍，然后通过微信 / QQ 联系你购买。

网站只负责展示，不收款、不下单、不发货。

## 2. 和参考站的对照

参考站是发卡平台上的一个店铺页。它的页面结构可以直接借鉴，和交易有关的部分全部去掉。

| 参考站上的模块 | 首版怎么处理 |
|---|---|
| 店铺头部（头像、店名、「联系 TA」） | 保留 |
| 店铺公告（页面顶部显示，首次进入弹窗，可点「不再提醒」） | 保留 |
| 分类卡片（带商品数量）和搜索框 | 保留 |
| 商品卡片（缩略图、标题、价格、缺货标记） | 保留，另加标签和划线原价 |
| 商品描述（图文、彩色强调文字） | 保留，改成每个商品一个独立页面，方便把链接发给别人 |
| 底部购买栏（数量、金额、「确定订单」） | 改成「联系购买」栏 |
| 填写邮箱、优惠券、支付方式 | 去掉 |
| 查询订单、投诉订单、消息、反馈 | 去掉 |
| 平台顶栏（开店指引、卖家中心等） | 去掉 |

## 3. 前台功能（访客看到的）

### 3.1 首页

- **店铺头部**：头像、店名、一句话简介、「联系我」按钮。
- **公告**：显示在头部下方。可以在后台打开「首次进入弹窗」，访客点「不再提醒」后不再弹出。
- **分类**：一排分类标签，每个标签带商品数量，默认选中「全部」。
- **搜索**：按商品名称和标签即时筛选，不跳转页面。
- **商品列表**：卡片网格，手机 1–2 列，电脑 3–4 列。每张卡片显示封面图、名称、价格（可带划线原价）、标签和缺货标记。置顶商品排在最前。
- **页脚**：版权文字和备案号（如有）。

### 3.2 商品详情页

- 每个商品有固定网址，可以直接转发到微信 / QQ。
- 内容包括：图片、名称、价格、标签、状态和图文详情。详情支持标题、列表、加粗、彩色强调、插图和链接。
- 页面底部固定一条「联系购买」栏，手机上始终可见。
- 缺货的商品仍然可以查看，按钮文字变成「暂时缺货，可咨询到货时间」。

### 3.3 联系购买

点「联系购买」后弹出联系面板：

- **微信**：显示微信号，一键复制，并展示二维码供长按识别。
- **QQ**：显示 QQ 号，一键复制，点击可直接唤起 QQ 聊天窗口。
- **其他方式**（Telegram、邮箱等）：后台填了才显示。
- **一键复制咨询语**：自动生成「你好，我想了解【商品名】（¥70）」。访客粘贴发给你，你马上知道对方要买什么。
- 可以设置一句回复说明，例如「9:00–23:00 在线」。

### 3.4 外观与体验

- **手机优先**：访客多数会从微信 / QQ 里点开链接，所以首要适配手机和微信内置浏览器。电脑端同样完整可用。
- **视觉**：采用「极光 Aurora」风格，详见 [UI 设计说明书](ui-design.md)。支持浅色 / 深色自动切换，主题色可在后台修改。
- **速度**：国内网络下首屏 2 秒内出内容。图片自动压缩并懒加载。
- **细节**：图片加载占位、搜索无结果时的空状态、缺货商品灰显、按钮点击反馈。

## 4. 后台功能（你自己用的）

浏览器打开 `/admin`，输入密码登录。手机上也能操作。

| 模块 | 能做什么 |
|---|---|
| 商品管理 | 新增、编辑、删除、复制商品；上架 / 下架；标记缺货；置顶；调整排序；在列表里直接改价格 |
| 分类管理 | 新增、改名、排序、删除 |
| 店铺设置 | 店名、头像、简介、公告及是否弹窗、联系方式、主题色、页脚文字和备案号 |
| 图片 | 上传时自动压缩并生成缩略图 |
| 数据备份 | 一键导出全部数据（商品和图片） |

商品字段：

| 字段 | 说明 | 必填 |
|---|---|---|
| 名称 | 商品标题 | 是 |
| 价格 | 填数字，也可以填「面议」这类文字 | 是 |
| 状态 | 在售 / 缺货 / 下架，默认在售 | 是 |
| 分类 | 不选则归入「未分类」 | 否 |
| 原价 | 填了就显示划线价 | 否 |
| 封面图 | 不传则用默认占位图 | 否 |
| 标签 | 例如「质保 30 天」「热卖」「新品」，卡片上最多显示 3 个 | 否 |
| 详情 | 图文编辑器 | 否 |
| 置顶、排序 | 控制在列表中的位置 | 否 |

## 5. 部署与运维

- **资源**：整站是一个轻量服务加一个数据库文件（SQLite），预计内存占用在 300MB 以内，8G 内存、无 GPU 的服务器足够。首版不在服务器上运行任何 AI 模型。
- **部署**：用 Docker 一条命令启动，自动配置 HTTPS。
- **数据**：全部数据就是一个数据库文件和一个图片文件夹，备份和迁移只需拷贝这两样。
- **安全**：后台密码加密存储，登录失败次数有限制。前台只做展示，不收集访客信息。
- **服务器与域名**：使用海外服务器和已有域名，不需要 ICP 备案。访客主要在国内，所以全部资源放在自己服务器上，不引用境外公共 CDN，保证打开速度。

## 6. 首版不做

在线下单、支付、自动发货 / 卡密、订单查询、优惠券、购物车、访客注册登录、评论、在线聊天客服、多管理员、多语言、访问统计。

这些以后都可以按需要再加。

## 7. 需要你确认的几点

| 问题 | 你不回复时的默认做法 |
|---|---|
| 要展示哪些联系方式？ | 微信和 QQ |
| 怎么维护商品？ | 带管理后台，在浏览器里改（另一种做法是不要后台、直接改配置文件，更简单但改起来不方便） |
| 大概有多少商品？ | 按 100 个以内设计，几百个也能正常使用 |
| 店名、头像、公告内容？ | 先用占位内容，上线前在后台替换 |

已确认的事项：

- 部署在海外服务器，使用已有域名。
- 视觉风格按 [UI 设计说明书](ui-design.md) 执行，效果见 [预览页](ui-preview.html)。

## 8. 完成标准

- 在手机微信里打开首页，可以浏览、按分类筛选、搜索商品。
- 点进商品详情，点「联系购买」可以复制微信号、唤起 QQ。
- 在后台新增一个商品、改一次价格，前台立即生效，整个过程不超过 1 分钟。
- 服务器重启后数据不丢失。
